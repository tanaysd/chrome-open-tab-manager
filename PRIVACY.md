# Privacy Policy – Open Tab Transfer

Open Tab Transfer is designed to be private by default.

## Data the extension accesses
- Open tab metadata in the current browser window (URL, title, pinned state) when the user clicks Export.
- JSON file content selected by the user when they click Import.

## Data handling
- Data is processed locally in the browser.
- The extension does not transmit tab data to remote servers.
- The extension does not include analytics, advertising, or tracking.

## Encryption
- Users may choose to encrypt exported files with a passphrase.
- Encryption uses PBKDF2 + AES-GCM via browser Web Crypto APIs.

## Data retention
- The extension does not maintain a backend or cloud database.
- Exported files are saved only where the user chooses.
